# 自架字體

這個目錄裡的 woff2 檔取自 Google Fonts，隨專案一起散布。

| 字體 | 用途 | 授權 | 版權 |
|---|---|---|---|
| Azeret Mono | 英文與數字 | SIL Open Font License 1.1 | Copyright 2021 The Azeret Project Authors（https://github.com/displaay/azeret） |
| Noto Sans TC | 中文 | SIL Open Font License 1.1 | Copyright 2014-2021 Adobe（http://www.adobe.com/），Reserved Font Name 'Source' |

授權全文見 `OFL-AzeretMono.txt` 與 `OFL-NotoSansTC.txt`。OFL 允許隨軟體一起散布，
但要求附上授權與版權聲明，這兩個檔案即為此。

`fonts.css` 與所有 woff2 由 `scripts/fetch-fonts.sh` 產生，可重跑以更新或更換字體。
