Donut AI Note
開箱指南

在瀏覽器按下錄音，會議結束就有一份依議題分段的筆記，連同待辦一起寫進你的 Notion。全程在你自己的電腦上跑——除了送去 Gemini 分析的那一次，而那份雲端副本在分析結束當下就被刪掉。

  • macOS 專用
  • 需要 Google Chrome
  • 需要 Node.js 20+
  • 約 20 分鐘
  • 不產生費用

最快的方法

把這段話貼給 AI，就不用往下讀了

如果你在用 Claude Code、Cursor 或任何能操作終端機的 AI 助理，不必自己照著步驟做。複製下面這段貼過去，它會一路帶著你走，缺什麼會主動問。

請幫我安裝 Donut AI Note，這是一個 macOS 專用的會議錄音工具：
https://github.com/uatcathay/donut-ai-note

請幫我做這些：
1. clone 到我的家目錄底下（不要放在「下載」資料夾）
2. 執行 npm install，然後跑 npm test 確認測試全過
3. 執行 bash scripts/install-launchagent.sh 讓服務常駐
4. 確認 http://localhost:3737/ 打得開

過程中需要三個金鑰（Gemini API key、Notion token、Notion 資料庫 ID）。
請逐項告訴我去哪裡申請、以及怎麼自己填進 .env 檔——
不要叫我把金鑰貼進對話裡。

最後請告訴我怎麼在 Chrome 把它裝成 App 並固定到 Dock。
每一步做完請告訴我要看到什麼才算成功。

AI 可以代勞

  • 抓下程式、安裝相依套件
  • 跑測試確認沒問題
  • 設定背景服務常駐
  • 出錯時看 log 幫你判斷

只有你能做

  • 申請三個金鑰、填進 .env
  • 在 Notion 建資料庫並加 Connections
  • 在 Chrome 按「安裝頁面為應用程式」
  • 第一次錄音時允許麥克風

不要把金鑰貼進 AI 對話。金鑰等同你的帳號權限，自己填進 .env 就好——那個檔案只留在你的電腦上，不會被上傳也不會進版控。上面的提示詞已經寫明這一點。

想自己掌握每一步

八個步驟，每一步下面都有一塊「怎麼知道成功了」。沒看到預期結果就先別往下走——在原地排查，比裝到第七步才發現第三步錯了容易得多。交給 AI 裝的人卡住時，也可以直接翻到最後的疑難排解。

01

確認 Node.js 裝好了

Node 是這個工具的執行環境。打開「終端機」（應用程式 → 工具程式，或按 ⌘空白鍵搜尋 Terminal），貼上：

$ node -v
怎麼知道成功了

出現 v20.x.x 或更高的數字就可以了。

出現「command not found」表示還沒安裝——到 nodejs.org 下載 LTS 版本，一路按下一步，裝完把終端機關掉重開再試一次。

02

把程式抓下來

選一個放得住的位置（別放「下載」，之後不小心清掉就麻煩了），例如家目錄底下：

$ cd ~
$ git clone https://github.com/uatcathay/donut-ai-note.git
$ cd donut-ai-note
怎麼知道成功了

執行 ls 會看到 src、public、scripts、README.md 這些名字。

之後不要搬動這個資料夾。背景服務記的是絕對路徑，搬走之後會失效。真的要搬，搬完重跑一次步驟 5 的指令即可。

03

安裝相依套件

$ npm install
怎麼知道成功了

跑完沒有紅色的 ERR!，資料夾裡多出一個 node_modules。接著跑 npm test，應該看到 pass 151、fail 0。

測試全過代表程式本身沒問題，接下來只剩你的金鑰設定。

04

拿三把鑰匙

先建立設定檔，再把三個值填進去。這個檔案只留在你自己的電腦上，不會被上傳，也不會進版控。

$ cp .env.example .env
$ open -e .env

第二行會用「文字編輯」打開設定檔。三個值分別這樣拿：

  1. GEMINI_API_KEY（必填，免費）
    到 aistudio.google.com/apikey 用 Google 帳號登入 → Create API key → 複製整串貼到等號後面。
  2. NOTION_TOKEN（想寫進 Notion 才需要）
    到 notion.so/my-integrations → New integration → 取個名字（例如 Donut）→建立後複製 Internal Integration Token。
  3. NOTION_DATABASE_ID（想寫進 Notion 才需要）
    在 Notion 建一個資料庫放會議紀錄，每場會議會變成裡面的一列。這個資料庫必須有兩個欄位： Name（標題型態）和 Date（日期型態），名字要一模一樣。

最容易漏的一步：把資料庫分享給 integration。

在資料庫頁面右上角 ••• → Connections → 選你剛建立的 integration。沒做這一步的話 Notion 會拒絕寫入，而錯誤訊息只會說「找不到資料庫」，很難聯想到是權限問題。

做完之後，複製資料庫網址裡 notion.so/ 之後、? 之前那段 32 碼英數，貼進 NOTION_DATABASE_ID。

怎麼知道成功了

三行都有值、等號後面沒有多餘的空格或引號，存檔關閉。

Notion 那兩個留空也能用——結果會改存成桌面的 .md 檔，功能完全正常，只是少了自動歸檔。

05

讓服務常駐

這一步會設定成每次開機登入時自動在背景啟動，之後你不用再碰終端機。

$ bash scripts/install-launchagent.sh
怎麼知道成功了

終端機印出 已安裝並啟動。接著在 Chrome 開 http://localhost:3737/，應該看到一個乾淨的錄音畫面，中間一支麥克風。

如果印出「連接埠已被占用」，表示你有別的程式在用 3737。腳本會拒絕安裝而不是裝出一個壞掉的服務——把那個程式關掉再跑一次就好。

06

裝成 App

上一步那個網址已經能用了，但每次開瀏覽器找分頁很麻煩。把它裝成獨立的 App：

  1. 在 Chrome 一般分頁開 http://localhost:3737/
  2. 點右上角 ⋮ → 投放、儲存及分享 → 安裝頁面為應用程式
  3. 確認之後，Chrome 會馬上開一個沒有網址列的獨立視窗
  4. 趁它還開著，對 Dock 上那顆甜甜圈圖示按右鍵 → 選項 → 保留在 Dock
怎麼知道成功了

Dock 上有一顆甜甜圈，點了會開出獨立小視窗。

視窗剛開時標題列會閃一下 localhost:3737 再消失——那是 Chrome 在告訴你這個沒有網址列的視窗來自哪裡，所有 PWA 都這樣，不是異常。

07

第一次錄音

點 Dock 上的甜甜圈，標題留空，按中間的麥克風，對著電腦講十幾秒（隨便講，例如念一段今天的行程），然後按中間的方塊停止。

第一次會跳出麥克風權限，要按「允許」。不小心按到封鎖的話，到 Chrome 設定 → 隱私權和安全性 → 網站設定 → 麥克風，把 localhost:3737 改回允許。

怎麼知道成功了

停止後畫面出現三個跳動的方塊和 Analyzing with Gemini…，下面顯示目前在做什麼（上傳音檔 → 分析錄音 → 寫入筆記）。十幾秒的錄音通常十秒內跑完。

跑完直接顯示摘要卡片，裡面有 📝 Mins，有談到待辦的話還會有 ◻️ What's next?。

08

確認寫進 Notion

回到你在步驟 4 建立的那個資料庫。

怎麼知道成功了

資料庫多出一列，Name 是 AI 給的標題、Date 是今天。點進去會看到議題摘要，最底下有一個叫「完整逐字稿」的子頁。

沒有新的一列，但畫面顯示成功？那多半是結果存成桌面的 .md 了——表示 .env 的 Notion 兩項沒生效，回步驟 4 檢查，特別是 Connections 那一步。

再走一次這五件事

前面八步是把它裝起來，這五件是確認你日常會用到的行為都正常。

01
關掉視窗再點開關閉 App 視窗只是關視窗，背景服務還活著。再點 Dock 圖示應該幾乎瞬間開啟。
02
重新開機開機登入後不用做任何事，直接點 Dock 圖示就能用——服務會自己啟動。
03
錄音中按暫停再繼續計時器會停住再接續，波形跟著停跟著動。暫停的時間不算進錄音長度。
04
分析途中按「先去錄下一場」會回到待機頁，剛才那筆出現在下方的分析清單裡標示「分析中」，繼續在背景跑。你可以立刻開始錄下一場會議。
05
看一眼分析清單跑完的會變成「已完成」，點「查看摘要」可以回頭看，按「移除」把那列收掉。失敗的會留在清單上顯示「待分析」，按「立即分析」可以重試——錄音不會因為分析失敗而消失。

遇到問題時

行為異常時第一件事是看 log：~/Library/Logs/donut-ai-note.log。用「主控台」App 開，或在終端機跑 tail -50 ~/Library/Logs/donut-ai-note.log。每一行都有時間戳記。

你看到的原因怎麼辦
點圖示出現連線錯誤背景服務沒在跑 終端機進到專案資料夾，重跑 bash scripts/install-launchagent.sh
搬動資料夾後就壞了服務記的是絕對路徑 同上，重跑一次安裝腳本就會用新路徑覆寫
Gemini 目前忙碌，已自動重試多次Google 那端容量不足，跟你無關 錄音已保留在分析清單，過一陣子按「立即分析」。離峰時段成功率明顯較高
已達每日用量上限免費版額度用完 訊息會直接告訴你幾點恢復（台灣時間下午三點或四點）。在那之前照樣可以錄，錄音會排在清單上等
錄完畫面說「上傳失敗」錄音送不到本機服務 多半是服務剛重啟。按「再試一次」即可，錄音還在記憶體裡
Notion 沒有新的一列integration 沒有被加進資料庫的 Connections 回步驟 4 那塊紅色提醒。這是最常漏的一步
麥克風沒反應權限被封鎖 Chrome 設定 → 網站設定 → 麥克風 → 把 localhost:3737 改成允許
錄很久之後自己停了到三小時上限，這是刻意的 再久會超過上傳大小限制，那樣整段錄音都救不回來。它會自動停止並開始分析

不想再用的時候
bash scripts/install-launchagent.sh --uninstall 停掉背景服務，再到 Chrome 的 chrome://apps 對 Donut AI Note 按右鍵移除。兩步都做完才算乾淨。
